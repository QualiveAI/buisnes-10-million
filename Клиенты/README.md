# Клиенты

Здесь ведутся отдельные рабочие папки по клиентам: исходные материалы, ссылки на аудиты, зафиксированные боли, предложения, договорённости и следующие действия.

## Клиенты
- [Экстендеры Пенимастер](./Экстендеры%20Пенимастер/README.md) — первый клиент в реестре; есть продуктовый и контентный аудиты, список заявленных проблем.

## Правила ведения
- Разделять подтверждённые слова клиента и наши гипотезы.
- Не перезаписывать исходные аудиты: хранить ссылки на оригиналы.
- Файл с вариантами решения заполнять только после отдельного согласования.
- Не добавлять в репозиторий пароли, токены, персональные данные покупателей и закрытые выгрузки.
