# Профиль основателя для сайта

На сайте обязательно нужен настоящий портрет основателя и подтверждённая биография. В текущем контексте нет самого фото и проверенного списка регалий, поэтому ничего не выдумываем.

## Что загрузить/подтвердить
- [ ] Фото основателя в хорошем качестве (желательно вертикальный портрет, исходник без сильной обработки).
- [ ] Имя и фамилия для публичного использования.
- [ ] Текущая роль/должность и название бренда/компании.
- [ ] Стаж: с какого года и в каких направлениях.
- [ ] Подтверждённые профессиональные достижения и цифры.
- [ ] Образование, сертификаты, награды — только если релевантны и подтверждаемы.
- [ ] Ссылки на публичные профили/публикации/выступления.
- [ ] 3–5 наиболее сильных стоматологических кейсов.
- [ ] Что именно можно публично показывать из клиентских материалов.

## Фото: требования к размещению
- Предпочтительный формат: JPG/PNG/WebP, минимум 1200 px по длинной стороне.
- Сделать кропы: вертикальный hero, квадратный аватар, карточка «Об эксперте».
- Не изменять лицо генеративно, не дорисовывать одежду/регалии и не выдавать сгенерированный портрет за реальный.
- Добавить alt с именем только после подтверждения имени.

## Биография — шаблон
«[Имя Фамилия] — [роль]. Работает с [типы клиентов] в задачах [подтверждённые направления]. В проектах отвечает за [реальные обязанности]. Примеры работ: [ссылки/описания].»

## Публичные proof points
Для каждого факта указать:
- утверждение;
- подтверждающий источник/ссылка/артефакт;
- можно ли публиковать;
- дата последней проверки.

До заполнения этих полей на сайте оставить placeholder для владельца, но не показывать выдуманные достижения.
