# CRM — Путь к 10 миллионам

Откройте [интерфейс CRM](./index.html), база — [leads.json](./leads.json).

## Хранение
Это статическое приложение без серверной БД. Изменения сохраняются в localStorage только текущего браузера и не пишутся в GitHub автоматически. Экспортируйте JSON-бэкап для переноса или CSV аналитики для разбора в ChatGPT.

## Ежедневно
1. Проверить сайт/профиль и деловой канал.
2. Разделить наблюдаемый факт и гипотезу, исправить приоритет и скоринг.
3. Записать результат касания, следующий шаг и дату.
4. В конце дня нажать «Экспорт аналитики CSV» и прислать файл в чат.
5. Не считать публичный контакт согласием на рекламу; проверить правила канала и требования закона.

90 записей — кандидаты для исследования, не квалифицированные лиды. Часть записей требует проверки первоисточника, точного профиля или официального сайта. Дата формирования: 2026-10-23.
