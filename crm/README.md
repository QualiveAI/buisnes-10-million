# CRM — Путь к 10 миллионам

Откройте [интерфейс CRM](./index.html), база — [leads.json](./leads.json).

## Структура
- 30 стоматологических кандидатов: Саратов, целевой профиль — средний / средний+; часть записей требует подтверждения официального сайта и масштаба.
- 25 интернет-магазинов и коммерческих каталогов.
- 20 юридических компаний и компаний ремонта под ключ.
- 15 производственных и B2B-предприятий.
- 100 PHP-кандидатов для проверки технологии и статуса исправлений.

## PHP2Shell
PHP2Shell — уязвимости серверного PHP, а не отдельная уязвимость WordPress-плагина. CMS/PHP не подтверждены автоматически; не заявлять, что конкретный сайт уязвим. WordPress, Joomla, Drupal, OpenCart и самописные PHP-приложения могут быть кандидатами; Tilda/Wix/Shopify не включать в PHP-оффер без отдельного PHP-компонента под управлением клиента. Исправленные версии актуальных веток по опубликованным рекомендациям: PHP 8.2.35, 8.3.36, 8.4.27, 8.5.12. Для старых веток проверять backport у поставщика ОС/хостинга.

## Хранение
Статическое приложение без серверной БД. Изменения сохраняются в localStorage текущего браузера и не пишутся в GitHub автоматически. Экспортируйте JSON-бэкап и CSV аналитики. При загрузке обновлённой базы справочные поля обновляются, а рабочие статусы и касания по совпадающим ID сохраняются.

## Ежедневная работа
1. Проверить официальный сайт/профиль и деловой канал.
2. Отделять наблюдаемый факт от гипотезы.
3. Для PHP-кандидата подтвердить платформу, серверный PHP и исправление до оффера на устранение.
4. Записать результат касания, следующий шаг и дату.
5. В конце дня экспортировать JSON и CSV.
6. Публичный контакт не равен согласию на рекламу; проверить допустимость канала и требования закона.

Все записи — кандидаты для исследования, не квалифицированные лиды и не подтверждённо уязвимые сайты. Дата обновления: 2026-10-23.
