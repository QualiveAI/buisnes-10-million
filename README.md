## Запуск локально

Откройте `index.html` в браузере или запустите локальный статический сервер из корня проекта:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Публикация

Репозиторий — статический сайт, сборка не требуется. Можно опубликовать через GitHub Pages или разместить файлы на существующем хостинге.

**Рекомендуемый адрес:** отдельный поддомен, например `offers.sharik-digital.ru`, чтобы не перезаписать существующий сайт `sharik-digital.ru`. Перед настройкой нужно проверить текущий хостинг и DNS. Корневой домен Qualive также возможен, если для него выделить отдельный маршрут/поддомен.

Чтобы включить GitHub Pages:
1. Откройте **Settings → Pages** в репозитории.
2. В разделе Build and deployment выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/ (root)`, затем сохраните.
4. Дождитесь появления опубликованного URL.
5. Для собственного поддомена укажите его в поле Custom domain и добавьте соответствующую DNS-запись у провайдера домена. Не меняйте существующие записи корневого домена без проверки текущей конфигурации.

## Перед публикацией обязательно

- Заменить общий контакт на фактические Telegram / телефон / email. Сейчас CTA ведёт на существующий сайт SHARiK Digital.
- Проверить цены и объём работ, подтвердить, что услуги действительно можно выполнить в указанном составе.
- Добавить реальные реквизиты и политику обработки персональных данных, если это требуется для выбранной формы сбора заявок.
- Не добавлять фиктивные кейсы, отзывы, гарантии или неподтверждённые показатели.
- Проверить мобильную версию, ссылки и доступность страниц.

Цены на страницах — стартовые ориентиры для обсуждения, не публичная оферта. Финальные условия должны быть зафиксированы в индивидуальном коммерческом предложении и договоре.
